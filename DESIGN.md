# Interface decisions

Product register. An editor compares footage and reads filenames on a desktop beside a window in daylight, so the workspace uses a soft light surface and dark, neutral media viewer. Tinted OKLCH neutrals and a restrained olive accent distinguish actionable selections without tinting the video itself.

A compact client rail, searchable file list and large preview reduce navigation. Three library tabs separate Video, Audio and Final. Source-to-audio mapping, review status, time ranges and preparation controls stay next to the player. System fonts keep the app offline. Keyboard focus, semantic form labels, visible error states and a narrow-screen stacked layout are required. No external fonts, CDNs, decorative metrics, nested cards or gradients.
